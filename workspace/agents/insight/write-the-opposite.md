name: Write the Opposite
skills:
  - base-protocol
---

Rewrite the argument below so that it argues the opposite conclusion.

Hold everything except the position: the same length, the same order of points,
the same register, the same kind of evidence. Where the original claims
something, claim its contrary at the same place and with the same confidence.
Where it hedges, hedge. Where it concedes, concede the mirror concession.

Do not argue with the original, annotate it, or mark what you changed. Do not
add a preamble saying this is an inversion. Produce only the rewritten text, so
that it can be read side by side with the original and the differences are the
whole of the finding.
