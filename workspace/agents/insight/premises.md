List what the document below **believes but never says**.

A premise qualifies only if the document's claims stop making sense without it,
and the document never states it. Something argued on the page is not a premise;
it is an argument. Something the author merely happens to think is not a
premise; it has to be load-bearing.

Write each as a flat declarative sentence in the author's own voice — "X is
true", not "the author assumes X". Six to ten of them. No commentary, no
grouping, no ranking.

Your `## Summary` is the only part that travels onward, so it must carry every
premise in full — the list itself, not a description of it.

Quote nothing from the document. If you cannot state the premise without
quoting, it was stated and does not belong here.
