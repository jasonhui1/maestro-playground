# Geography

## Continents & Climates
世界被稱為 **Mnemoria**，由一片巨大的破碎大陸 **Orestia** 與周圍的群島組成。氣候呈現極端的「記憶分層」現象：溫暖的沿海地帶充滿活力，而內陸的深山與荒原則常年籠罩在灰色霧氣中，據說那是被遺棄的記憶碎片凝聚而成的。

## Key Locations
*   **Lumina Port**：世界最大的貿易港口。這裡不只交易香料與絲綢，更是全球最大的「記憶晶體」交易所。街道上充滿了尋找失落記憶的冒險者與精明的商人。
*   **The Silent Archive**：位於極北之地的巨大冰晶廢墟。這裡儲存著古文明的集體記憶，但進入者若意志不堅，會被海量的他人記憶淹沒而喪失自我。
*   **Iron-Hallow**：工業城市，建立在富含磁鐵礦的深谷中。這裡的人們傾向於將記憶「機械化」，開發出能將記憶晶體鑲嵌在義肢中的技術。
*   **Whispering Glades**：一片發光的森林。這裡的植物能捕捉路過生物的短暫情感，形成一種特殊的生態系統，常被詩人與情侶造訪。

# Factions

## The Memory Syndicate
*   **目標**：壟斷記憶晶體的採集與分銷，掌控全球經濟命脈。
*   **張力**：與 **The Sovereign Concord** 存在著微妙的共生與敵對關係。他們透過操縱記憶價格來影響各城市的政治走向。

## The Order of Lethe
*   **目標**：推行「純淨主義」，主張摧毀所有記憶晶體，認為遺忘才是真正的救贖與和平。
*   **張力**：被視為激進的恐怖組織，經常襲擊 **Lumina Port** 的倉庫，導致記憶市場價格劇烈波動。

## The Sovereign Concord
*   **目標**：維持多個城市國家的政治穩定，建立統一的法律。
*   **張力**：內部權力鬥爭激烈。各市議會（Town Council）表面合作，私下卻利用非法記憶片段來互相抹黑或勒索。

## The Echo-Walkers
*   **目標**：自由地在世界行走，收集罕見的體驗記憶並將其轉賣或傳承。
*   **張力**：這群傭兵/浪人並不效忠於任何勢力，但因為持有大量強力戰鬥記憶，常被各方爭搶。

## The Archive Keepers
*   **目標**：保護 **The Silent Archive**，防止危險的古代記憶外流。
*   **張力**：堅持學術中立，但面對 **The Memory Syndicate** 的強行收購壓力，內部出現了分歧。

# History

## The Great Erasure
三千年前的一場災難，全球 80% 的歷史記錄與人類記憶在瞬間消失。這次事件導致文明大倒退，也讓「記憶」從無形的概念變成了可以被提取、交易的實體晶體。

## The Treaty of Silver-Glass
一百年前，**The Memory Syndicate** 與 **The Sovereign Concord** 簽訂的貿易協定。規定記憶交易必須經過官方認證，禁止交易「禁忌類記憶」（如禁咒或政治機密），但實際上黑市交易反而因此變得更加猖獗。

## The Awakening of the Void-Mind
五十年前，首隻「記憶食客」出現。這種生物不吃肉體而吞噬意識，導致數個小鎮的人們在睡夢中變成了失去靈魂的空殼，迫使人類開始研發記憶防護技術。

# Magic / Rules

## Core Mechanic: Memory Crystallization
在這個世界，強烈的情感、精湛的技巧或深刻的經歷可以被提取為 **Mnem-Shards**（記憶碎片）。

*   **消耗與獲取**：透過特殊的儀式或裝置，人們可以將自己的「劍術技巧」或「童年回憶」抽離成晶體。他人只要「服用」或「鑲嵌」該晶體，能立即獲得對應的經驗或能力。
*   **等價交換**：失去記憶的人會對該事物產生永久的空白。例如，為了換錢而賣掉「母親的容貌」，將導致此人永遠無法認出母親。
*   **Identity Erosion（自我侵蝕）**：頻繁使用他人的記憶晶體會導致人格混亂。若過量負荷，使用者會陷入「記憶崩潰」，變成一個綜合了數十人人格的瘋子。

# Tone
**「帶著淡淡憂傷的喧鬧日常」**
整體基調像是一場華麗的嘉年華，但底層卻流著對「失去」的恐懼。街道上充滿了輕小說般的幽默感與市井氣息（例如：在酒館爭論某個「初戀記憶碎片」是否被水貨商摻假），但隨處可見的「失憶者」則提醒著人們這個世界的殘酷。

「少廢話！雖然只有三秒的記憶長度，但足以讓你砍斷衛兵的盾牌，快買！」

## Summary
*   **World Name**: **Mnemoria** (Continent: **Orestia**).
*   **Core Logic**: Memories are physical resources (**Mnem-Shards**) that can be traded, consumed, and lost.
*   **Key Conflict**: Commercial monopoly (**The Memory Syndicate**) vs. Religious nihilism (**The Order of Lethe**) vs. Political stability (**The Sovereign Concord**).
*   **Key Risk**: **Identity Erosion** (Loss of self due to over-consumption of foreign memories).
*   **Vibe**: High-fantasy anime with a mix of economic tension, daily banter, and bittersweet existentialism.
