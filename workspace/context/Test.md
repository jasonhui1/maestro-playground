# Geography: Aethelgard

這個世界是由無數漂浮在雲海之上的島嶼組成的群島體系，稱為 **Aethelgard**。這裡沒有傳統意義上的「地面」，只有深不見底且充滿劇毒霧氣的 **Cloud Sea**。

*   **The Gilded Heights**：位於最高海拔的奢華群島。氣候永恆如春，建築多以白色大理石與金箔構成。這裡的居民享受著最純淨的魔力流，但空氣稀薄，外來者常感到呼吸困難。
*   **The Rust Bottoms**：位於雲海邊緣的底層島嶼。氣候潮濕且陰森，常年被灰色的酸雨籠罩。這裡充斥著廢鐵工廠與貧民窟，是維持整個世界浮力的「維修車間」。
*   **Lumina Port**：橫跨三個島嶼的大型貿易港口。這裡是 **Aethelgard** 的心臟，巨大的飛空艇在鋼鐵吊橋間穿梭。街頭充斥著叫賣聲、酒精味，以及來自各地的冒險者。
*   **The Silent Spire**：一座孤立在極北之地的黑色巨塔。傳說它是唯一觸及雲海底部的建築，周圍被永久的暴風雪包裹。

# Factions

1.  **The Gilded Syndicate**
    *   **目標**：壟斷「浮力水晶」的開採與分配權。
    *   ** tensão**：與 **Rust-Town Union** 處於極其緊張的勞資衝突中。他們將維修工視為可消耗的零件。
2.  **The Azure Hegemony**
    *   **目標**：恢復古老的血統純潔性，重建統一的帝國。
    *   ** tensão**：厭惡 **The Gilded Syndicate** 的金錢至上主義，認為商人不應掌握政治權力。
3.  **Ironbound Order**
    *   **目標**：維持群島間的秩序，實際上是最高級的僱傭兵集團。
    *   ** tensão**：雖然表面中立，但內部正分裂為「忠於契約」與「追求正義」兩派。
4.  **Void-Walkers**
    *   **目標**：研究 **Cloud Sea** 的真相，尋找傳說中的「真地面」。
    *   ** tensão**：被 **The Azure Hegemony** 定義為異端，在各個島嶼間秘密活動。
5.  **Rust-Town Union**
    *   **目標**：爭取基本的生存權與改善底層工作環境。
    *   ** tensão**：經常採取罷工或破壞浮力裝置來威脅上層社會。

# History

*   **The Great Descent**：數千年前，原本統一的大陸突然崩解，碎片化為如今的漂浮島嶼。這次事件摧毀了舊文明，倖存者被迫學習利用浮力水晶生存。
*   **The Silence of the Bells**：一次大規模的魔力風暴導致所有長距離通信水晶失效，導致數個小島在孤立中滅絕。這次事件讓人們意識到對水晶的高度依賴是極其危險的。
*   **The Treaty of Amber**：**The Gilded Syndicate** 與 **The Azure Hegemony** 簽署的停戰協定。雙方達成妥協：一方掌控金錢，一方掌控名義上的統治權，形成了一種病態的共生關係。

# Magic & Rules: Gravity Exchange

這個世界的魔力核心名為 **Gravity Exchange (重量交換)**。

*   **核心機制**：在這個世界，不存在「憑空創造」的浮力。若要讓一個物體變輕（甚至漂浮），必須將對等的重量「轉移」到另一個目標物上。
*   **等價原則**：一名法師若想讓自己輕盈地跳上屋頂，他必須將自己的重量暫時轉移到手中的法杖、地上的石頭，甚至是一名倒霉的同伴身上。
*   **感官特徵**：每當大規模的重量交換發生時，空氣中會突然瀰漫一種強烈的 **焦桂皮味 (Burnt Cinnamon)**。這成了法師現身的標誌，也是平民對魔力恐懼的嗅覺記憶。
*   **貨幣體系**：除了金幣，最高階的交易使用 **Audio-Crystals (音頻水晶)**。這些水晶能記錄短暫的聲音片段，越稀有、越具歷史價值的聲音（如已滅絕生物的鳴叫），價值越高。

# Tone & Daily Life

**色調**：充滿活力的「奇幻市井」與隱隱作痛的「階級崩壞」。

**日常片段**：
在 **Lumina Port** 的路邊攤，一名 **Ironbound Order** 的騎士正對著盤中的合成肉發牢騷。
「這東西的味道像是在嚼生鏽的鐵釘。」
旁邊的酒保翻了個白眼，乾脆地回答：「嫌難吃就去 **The Gilded Heights** 吃金箔，但記得先把你這身盔甲賣掉換路費。」
騎士冷哼一聲，將一枚紀錄著「暴風雨之夜」的音頻水晶拍在桌上，示意續杯。

## Summary

*   **World Name**: Aethelgard (Floating islands over the toxic Cloud Sea).
*   **Key Locations**: The Gilded Heights (Upper), The Rust Bottoms (Lower), Lumina Port (Trade hub), The Silent Spire (Mystery).
*   **Major Factions**: The Gilded Syndicate (Money), The Azure Hegemony (Bloodline), Ironbound Order (Mercenaries), Void-Walkers (Researchers), Rust-Town Union (Workers).
*   **Magic System**: Gravity Exchange (Weight must be transferred, not deleted).
*   **Sensory Marker**: High-level magic smells like burnt cinnamon.
*   **Unique Economy**: Audio-Crystals as high-value currency.
*   **Trope Subversion**: Magic is treated as a labor-intensive tool for buoyancy and transport rather than purely academic or combat-oriented.
